# Aset logo resmi

Letakkan logo resmi Gelar Rasa 2026 (dari panitia) di folder ini (dashboard/src/assets/brand/) dengan nama:

    gelar-rasa-2026-logo.png

Dashboard otomatis memakai file tersebut (rasio dan warna asli dipertahankan, tinggi 34–44 px).
Selama file belum ada, dashboard menampilkan slot placeholder berlabel "Logo resmi Gelar Rasa 2026".
Jangan mengganti dengan logo buatan ulang.
